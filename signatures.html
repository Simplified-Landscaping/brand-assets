Where to paste it

  1. Gmail: Settings (gear) → See all settings → General → Signature → Create new, then paste.
  2. Outlook desktop: File → Options → Mail → Signatures → New, then paste.
  3. Outlook web: Settings → Mail → Compose and reply → Email signature, then paste.
  4. Apple Mail: Settings → Signatures → +, then paste. Uncheck “Always match my default message font.”
